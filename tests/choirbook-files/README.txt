ChoirBook file compatibility fixtures
=====================================
Every file in this folder was written by an older version of the app. ALL of them must keep opening, forever.
When the file format changes (a new version number, or new settings), ADD a file for it here; never delete or edit the old ones.
Open tests/choirbook-compat.html (with the site running: python3 -m http.server 8000, then http://localhost:8000/tests/choirbook-compat.html).
